# 신규 미니게임 이미지 시안

기존 ST01의 블록형 섬·파란 지붕·목재와 석재·청록색 바다 스타일을 참고한 전용 배경 시안 5종입니다. 이미지 생성 도구를 사용했으며 프롬프트는 prompts.json에 저장했습니다.

| 파일 | 시각적 방향 |
|---|---|
| DS09_tree_structure.png | A~E 노드 건물과 좌우 연결 소켓, 부모·자식 관계를 만드는 정원 |
| ALG01_sorting.png | 인접 상자 5와 2의 교환을 강조한 정렬 작업대 |
| ALG02_binary_search.png | 정렬된 7칸, 현재 범위 경계와 중앙값 12를 강조한 서고 |
| SQL01_query.png | 원본 기록·부서 정보·JOIN·열 선택·필터·정렬·결과표로 이어지는 작업실 |
| DATA01_data_exploration.png | 원본 토큰·결측 및 중복 처리·필터·집계 그래프를 보여 주는 관측실 |

검토용 시안이며, 게임의 실제 조작 화면은 현재 신규 클릭 실습 UI로 구현되어 있습니다. 이 시안을 배경으로 적용할 때는 이미지에 포함된 숫자·노드 연결·선택 효과를 동적 오브젝트와 분리해야 합니다. 그림의 배치나 숫자는 각 레벨의 최종 규칙을 대신하지 않습니다.

분야별 메뉴와 신규 실습의 규칙 및 검증 방법은 프로젝트 루트의 MINIGAME_GUIDE.md에 정리되어 있습니다.
